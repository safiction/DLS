4. SHORT ANALYSIS
----------------------------------------
The cross-encoder helps because it reads the query and document jointly, capturing semantic relationships that bag-of-words BM25 and even the bi-encoder miss. BM25 matches tokens but ignores synonymy and word order; the bi-encoder compresses each text into a single vector, losing fine-grained interactions. The cross-encoder scores every pair from scratch, so it can spot relevance signals the first-stage scouts overlook.

Deeper reranking saturates because the cross-encoder is already very good at re-ordering the strongest candidates. Once k reaches ~20-50, the extra documents are low-quality tail items; the CE correctly pushes them down, so the top-10 barely changes. Meanwhile cost grows linearly with k (each extra doc is one forward pass). The sweet spot is where nDCG@10 curve flattens — usually between k=20 and k=50 for this corpus.
